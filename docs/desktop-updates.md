# Qt / Windows 软件更新

## 不需要为普通发布准备签名工具

默认流程：创建项目 → 上传文件 → 填版本说明 → 发布。服务器自动计算 SHA-256、分配发布序号，记录上传账号、发布账号和时间。项目所有者可设置一个额外的发布密码，数据库只保存 bcrypt 摘要。发布密码不是下载密码，也不写进客户端。

`fwtool` 只用于可选的高级 Ed25519 数字签名：私钥在发布者本地，公钥预置到客户端。账号署名回答“谁操作了网站”；数字签名回答“文件是否由独立可信密钥批准”。后者才能在网站被入侵时提供额外保护。普通模式无需 `fwtool`，但不能宣称具备这一额外保护。

旧签名项目保持原策略。所有者可在项目设置中改为账号模式，并验证当前账号密码；已预置公钥的客户端不会自动降级，必须在客户端主动调整策略。已有公钥不能随意替换；需要新密钥时新建项目或做受控客户端迁移。

## 两种简单更新

- **整包覆盖**：将 `windeployqt` 生成目录中的文件直接压缩到 ZIP 根目录，不额外套一层文件夹。上传 ZIP，选择“完整文件 / 软件整包”。示例更新器覆盖包中列出的文件，**不删除未列出的旧文件或用户数据**。不要把用户配置、日志、数据库放进发布包；需要完整卸载旧文件的产品应另做白名单迁移。
- **按文件更新**：上传一个 DLL、EXE 或其他普通文件，选择“按文件更新”，填写适用旧版本和相对目标路径，例如 `1.0.0`、`plugins/module.dll`。只有报告该旧版本的客户端才会收到这个更新，防止错误的依赖组合。

这里的按文件更新不是 bsdiff/xdelta 二进制差分。新 DLL/EXE 仍是完整文件；多个变更文件可先用整包 ZIP 分发。真正的差分还需旧文件精确摘要、补丁格式与资源限制，当前未实现。

更换 Qt 主版本、编译器、架构或 DLL ABI 时优先使用整包。32 位和 64 位项目/架构应分开，不要混用依赖。

## 客户端工作方式

`examples/qt` 提供检查、下载和安装入口；`cmd/update-agent` 是无网络的独立更新器。

1. Qt 客户端用当前版本检查更新；公钥留空为账号模式，有公钥则必须通过数字签名验证，绝不在失败后降级。
2. 下载到临时文件，核对 SHA-256 与大小后提交。
3. 用户明确选择软件目录、确认退出，Qt 将独立更新器复制到软件目录外的临时目录，写出本地安装计划并启动它，避免更新器占用自身待替换的 EXE。
4. 更新器最多等待指定主程序 120 秒退出，不强杀进程、不请求管理员权限。其他程序仍占用 DLL/EXE 时会报错并尝试恢复已替换文件。
5. 全部文件先解包到暂存区，再备份、替换。拒绝路径穿越、Windows 设备名/数据流、链接和大小写冲突；最多 4000 个 ZIP 条目，解包总量不超过 4 GiB。
6. 成功后记录本地 `.firmware-hub-version.json`。备份和恢复日志保留在软件目录；中途中断时不继续盲装，先执行回滚。安装计划旁保存 `.result.json`，Qt 下次启动会显示上次结果。不会自动执行包内命令或自动重启任意程序。

多文件替换不是断电原子事务。异常中断后可能暂时无法启动，须由保留在应用目录外的更新器恢复。应用目录应是本机可信、普通用户可写的独立目录；不要通过提权绕过权限，也不要允许其他低信任用户改安装计划。

Qt 示例仍是参考集成，不会给既有的所有 Qt 软件自动添加更新能力。实际产品应从自己的编译版本或可信本地版本台账取得“已安装版本”，不能把服务器返回的新版本直接当作已安装。

## 编译与恢复

```sh
go build -trimpath -o firmware-hub-update.exe ./cmd/update-agent
```

Windows 32 位软件环境可使用 `GOARCH=386` 编译更新器；64 位 Windows 也可运行该版本。Qt 程序、Qt DLL 与编译器运行库必须架构匹配。

手动运行本地计划或恢复最近一次更新：

```sh
firmware-hub-update.exe --plan package.install.json --wait-pid 1234
firmware-hub-update.exe --rollback "C:\Apps\Example"
```

PID 是自己的主程序进程号，不要复制示例数字。回滚检测到安装后文件被修改时会拒绝覆盖，保留备份供人工处理。旧成功备份会转存到 `.firmware-hub-backup-*`，不会静默清理；验证稳定后由管理员按需删除，避免磁盘逐渐占满。

测试：`tests/desktop-update.mjs` 使用本机隔离演示服务和临时应用目录，验证账号发布、真实 Qt 下载、整包安装、DLL 替换、版本台账、回滚、配置保留及匿名公开历史；不操作系统软件目录。
