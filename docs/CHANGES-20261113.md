# v0.4.0

# 2026-11-13 界面与配置更新

- 保留两栏登录页，统一工作区配色、表单间距和卡片边界；移除重复主题设置按钮。
- 初始不显示 TOTP 输入。仅在账号密码正确且该账户已启用 TOTP 时返回 mfa_required；未启用用户直接登录。验证码验证前不建立会话。
- 更新通知分为 Webhook / Telegram / MQTT 三个可独立启停的渠道；关闭保留连接信息与加密凭据。现有配置兼容，仍按原连接继续工作。
- 在项目“更新通知设置”中选择“共用：另一个项目”，引用同一所有者的连接；引用方开关独立，来源连接更新后同步生效，不复制/回显凭据。循环引用、跨所有者引用和过深链条拒绝保存并回滚。
- MQTT 支持主题模板 firmware/{project}/available，{project} 替换为接收项目标识。共用 Broker 时可以留空继承来源模板，也可以填写项目专用主题；Webhook/MQTT 内网目标许可按实际连接来源分别处理。
- 数据库使用新增 notification_options 表保存开关与引用，不重建旧库、不删除密钥、账号、版本或文件。升级前仍须备份完整 data。

部署前备份完整数据目录；此记录不代表镜像已发布。测试与发布状态以实际验收记录为准。

- 统一复选框尺寸及鼠标/键盘焦点、适度圆角；登录页不再显示部署维护命令，登录、公开版本与后台页面补齐版权提示。

- 登录页采用单列卡片适配平板和手机；后台手机导航统一为侧边抽屉。
