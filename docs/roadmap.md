# 开发范围

## 0.1：已实现的最小可运行闭环

多用户项目与角色；签名文件发布；安全 Markdown；按平台/型号/通道检查；历史与 Range 下载；设备独立凭据；三方可选心跳；MQTT/Webhook/TG 发布提醒；C/C++ SDK；Qt 下载验签与同进程续传；单容器和快照备份。

不把“可存储任意文件”宣称为“可安装到任意设备”。

## 0.2：简化发布与平台参考安装器

默认账号发布、可选项目发布密码、高级签名可选；上传/发布账号署名与时间；登录历史、会话撤销、项目操作审计；匿名公开项目目录。

Windows ZIP 整包覆盖与单文件更新参考代理，旧版本匹配、暂存、备份和回滚；原生 Qt 下载到安装闭环。不是二进制差分，整包不自动删除未列出的文件。

FH485/1 C 状态机与 Qt SerialPort 工具；新写的 N32G452 512-KiB 最小 Bootloader/app-v1/app-v2 可编译，仿真验证暂存摘要和复制中断恢复。**编译/仿真不等于真机验证**，首次烧录、连线和真实断电测试必须按具体板卡完成；不兼容未知厂商 Bootloader。

## 下一阶段

- 完整 TUF 元数据、根密钥轮换、委派与多签；受限 MCU 的能力档与威胁模型。
- WebAuthn、用户自行改密、邀请/注册策略、CI 专用上传身份（TOTP 已实现）。
- 配额/带宽策略、通知手动重试与外部审计导出（基本审计界面和历史 API 游标分页已实现）。
- 定时发布、灰度发布、设备分组与批次任务、失败阈值暂停。
- ESP-IDF、MCUboot/Zephyr、RAUC 等安装适配与真实板卡断电测试。
- S3/CDN、可选 mTLS、完整 OpenAPI 及生成型客户端。

## 可选协议扩展

- CoAPS/CoAP 分块下载适配。
- LwM2M Firmware Update 对接，不重造完整设备管理平台。
- 必要时支持 MQTT 固件分块；默认仍推荐 MQTT 提醒 + HTTPS 拉取。
- BLE/串口/CAN 由本地网关或上位机转发，不额外开放公网裸协议。

首版不包含这些后续功能，发布说明与测试报告也不会将其标记为已完成。
